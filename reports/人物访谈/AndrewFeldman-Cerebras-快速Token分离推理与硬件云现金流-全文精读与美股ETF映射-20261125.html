02合作与价格：快速token、OpenAI与分离推理

OpenAI关系与快速token的经济价值

【00:52】Gavin Baker 先问 OpenAI 领导层变化之后双方关系如何。Andrew Feldman 回答，OpenAI 是最重要客户之一，关于真实合作的许多网络说法不准确，只有双方少数人掌握全貌。Cerebras 正分大批交付容量，供 OpenAI 对外、部分未公布客户及内部用途。他没有披露逐项用途，而说双方继续埋头建设。

【01:49】Gavin 说 OpenAI 相关收入由二季度到三季度增长，四季度还会增长，Feldman 确认；再问 2027 是否持续增长时，他答“我们相信会”。应保留已发生变化、近季展望与更远期预期的区别，本场没有给出各季度 OpenAI 收入数，也没有把全年逐季增长变成无条件保证。

【02:42】主持引述特定客户付费可到每瓦 200 美元、按 GW 换算约 2000 亿美元，而普通市场理解可能是每瓦 50—60 美元。Feldman 没有深入客户细节，但认可该方向，强调前沿智能加快速 token 对买方有价值，对卖方有较高毛利。口述缺少计价期间、产品及利用率，不能当公司统一每瓦年收入或毛利承诺。

【03:51】Feldman 说过去六个月新增 AWS、Microsoft、Oracle 合作，均希望转售快速 token，原因是模型越强，响应快越有价值。他把这一逻辑用于开放和闭源模型，也提到 Fireworks 等伙伴。这里是在说明客户价值与渠道，不是公布所有合作都采用相同模式、毛利或收入确认方法，后面他会区分卖设备和经营云。

【04:45】Gavin 以股东身份说，若 OpenAI 退出旧约也许能按更高价卖给别人，并称旧约价格很优惠。Feldman 说合同签于 2025 年十二月底，此后电力与空间成本约涨四成，模型更聪明，快速 token 也更有价值。其回答既承认市场环境变化，也没有宣称想解除合作；主持的退出情景不是实际事件。

【05:39】谈新容量，双方提到相对旧约约 40%—50% 的更高价格只是下限，Feldman 说多数报价会更高。Gavin 据此把约 250 亿美元 RPO 设想为现价下约 370亿—375 亿美元；Feldman 只说会高很多。旧合同并未因此改价，也没有在此形成新增 RPO，主持的重算不能列为公司正式订单。

分离式推理：GPU处理输入，Cerebras生成答案

【06:27】被问如何提高每瓦 token 产出，Feldman 解释成熟计算会拆解任务、以不同硬件分别优化。推理可分为 prefill——处理用户输入提示，以及 decode——生成答案。二者需要不同资源，分离后可以各选合适的硬件，目的不是笼统宣布某芯片全面替代 GPU，而是发挥各自适合的部分。

【07:21】Feldman 说自己的机器两项都能做，但 decode 优势更大，所以用 GPU 做 prefill、Cerebras 做 decode；他声称在相同速度下可提高约五倍产出，以 10MW 机房作示例。字幕一处写 packets，随后明确谈 tokens。本文按整段意图还原为 token 吞吐，但它仍缺模型、批量、功率边界等可复现实验条件，不当成所有负载统一五倍。

【08:24】他表示已有 AMD 做 prefill、Cerebras 做 decode 的生产部署，并称是首个此类部署；把它推广到自身设备群，可增加可出售 token，效果类似获得更多机房容量。主持接着问能否配 NVIDIA，他说没有技术或运营阻碍，伙伴正在做。已生产部署与其他伙伴研发阶段应分别表达，不把所有组合都说成已全面上线。

【09:19】Feldman 说软件集成层可连接不同计算平台，列出 AWS Trainium、NVIDIA 及其他 GPU 的说法，目标是既服务新建站点，也可把自身设备加入既有 GPU 数据中心。他强调可组合性；本场未逐一提供所有平台认证或相同吞吐测试，因此不能把口述“能接”视为所有配置均已交付并达到相同性能。

03架构与路线：SRAM、晶圆面积和推理边界

为什么不用小改版GPU，而造一整片巨型芯片？

【10:57】略过关于业绩会打分的玩笑后，Gavin 回到初创战略：如果与 NVIDIA 用相同制程、相近 HBM 架构，却买晶圆和内存更贵，仅做小修改可能很难赢，还要面对 AMD、Trainium、TPU。他认为软件移植越来越容易，但真正差异化仍需硬件取舍，并请 Feldman 解释为什么选择晶圆级路线。

【11:45】Feldman 说初创若只是稍快、稍便宜，通常不足以成功；在主导架构上做细微改良，仍受巨头更低采购成本、制造资源与产品捆绑能力压制。NVIDIA 等能同时卖 CPU、交换机等，竞争不只是单颗芯片指标。他认为应选择不同工程路线，而非在对手最有规模优势的结构里做小幅优化。

【12:34】他回忆 2015 年末至 2016 年初，团队判断 AI 将带来计算革命；如果没有二十年图形历史负担，从白纸开始，会造什么？答案是巨型芯片，配上与主流不同的 SRAM。行业以前试过晶圆级且多次失败，他知道此路不是自然简单的改进，但认为 AI 和推理的重要性值得重新做。

【13:28】Feldman 展示其称为行业史上最大的芯片，口述面积约为此前芯片 56 倍、速度可快 15、20、30 倍。他同时说解决了大量技术问题，也花时间解释不同架构为什么不能完全沿用 GPU 指标。这些比较未附具体对象和工作负载，本文保留为公司说法，避免将其列成普适第三方性能排名。

【14:18】他用电动车被旧机械师追问排气歧管作类比，说明评价方式可能沿袭旧架构。当别人问大模型如何放进去、良率怎样实现，他的回答是采用不同于 GPU 的切分与工程解法，而不是逐项复制 GPU。类比说明思路，并没有在台上公开完整的良率数据或模型映射方法，技术解释的边界应保留。

【15:02】Feldman 明说，真正新架构的挑战既是发明，也是解释既有心智模型不适用；优势来自不同取舍，它也会在别的事情上较弱。这句限定十分重要，不能因为后面强调推理快，就把公司改写成训练、通用计算及所有应用都优于 GPU。Gavin 随后从同一晶圆约束出发，进一步聚焦内存容量和带宽的选择。

【15:52】Gavin 说，把晶圆切成小片加 HBM 的公司在容量、计算与带宽之间竞争，而 Cerebras 采用整片路线，对带宽作了特别取舍；他个人认为别人很难超越。Feldman 说确实很难。这是主持和管理层对架构位置的判断，没有本场统一实验或未来保证；随后讲的 SRAM 机制才是理解这一主张的依据。

【16:38】Feldman 简化说明两种内存选择：一种单位面积存得多但取数较慢，一种存得少但快。Cerebras 选 SRAM，要取得足够容量就需更多面积，因而走向晶圆级。主流 GPU 更多依赖高密度外部内存。他解释的是架构层次的取舍，不是声称 DRAM 完全没有用途或 SRAM 在每种成本与容量约束下都更好。

【17:24】他把关键洞见总结为：用更大面积容纳高速内存，解决推理中快速取数并送到计算单元的问题。自动字幕有一处把取数对象写为 wafers，但上下文明确是内存与计算的数据供给，本文不拿该词制造另一项技术论点。Gavin 接着问，如果三四年后不受供给限制，能与多少既有加速器搭配。

【18:11】Feldman 答“多数”。Gavin 假设即使 10% 也能对应数百亿美元收入，但没有完整模型；Feldman 随即限定，分离策略用于推理，训练市场必须排除。他认为对推理这是更优解。多数附着率是供给不受限的远期讨论，10% 与对应收入是主持算例，都不是公司正式收入指引。

【19:06】谈路线，Feldman 说刚开始交付的 CS4 比 CS3 快两倍；CS5 预计随后夏季交付，再快两倍；CS6 计划 2028 年夏季，至少再翻倍。他期待保持相对市场约十至三十倍速度位置。应分清正在交付的产品与未来目标，也不能用三次翻倍便直接推算收入八倍或所有模型性能相同。

【20:03】他把计算公司的路线拆成三件事：做运算、保存结果、把结果搬到有用的地方。因此会分别改进运算、内存访问及芯片外数据移动。他强调追求大步创新，不是小幅迭代。这段阐释为什么性能、内存和互联都在路线内，而不是单靠增加处理单元数量；仍没有公开每项成本与能耗细表。

「we're going to be weak at different things than other architectures」— Andrew Feldman，15:02

04兑现与责任：交付、硬件云现金流及最后三问

从大合同到收入：供应链和机房都有时差

【20:49】Gavin 试着还原大合同转收入：十二月订更多晶圆、春季拿到、做成服务器、再上电，三季度只含少量贡献，四季度中点约增长 40%。这段时序和数字是主持的归纳。Feldman 没逐项确认，下一段改为描述从二百多亿美元合同到供应扩张的实际过程，因此不能将整段主持推算写作公司正式逐季指引。

【21:35】Feldman 说，十二月二十五日拿到二百多亿美元级合同后，第二天就安排台湾行，与台积电及十到十五家主要供应商当面协商。他们能提高预测，但开始生产仍需几个月，新增量到五月或六月才出片。合同很大，不代表第二天就有更多可出售容量；供应安排是第一道时间差。

【22:23】同时公司签机房，但 2026 年初已难找，现在更难；部分原承诺三季度上电的延到四季度或次年一季度。因此芯片供应与制造扩展后，容量才逐步交付，后续几个季度继续释放。Gavin 据此推演四季度增幅只是开始、明年一季度或类似；Feldman 只说对一季度有很高期望，没有确认每季度同样增长率。

同一计算产品，两种不同现金流

【23:11】Gavin 问 Oracle、Microsoft 等设备销售与自建云有什么不同。Feldman 说卖硬件发货、确认收入、收款，现金流直接；坏处是大单不均匀，每季往往从零开始争取。自建云有多年合同和 backlog，进入新季度更有可见性。两者是同一计算产品的不同交付方式，各有优势和风险，不应只用收入增速来比较。

【24:01】他强调云业务资本密集，要先支付数据中心和自家设备成本，较好多年合同的设备回收期口述约一年到十八个月，具体表述有范围重复，不是所有成本统一回收期。硬件销售波动大，云收入持续但先用现金，两种模式需要用不同现金周转方式理解，不能把云合同金额直接当净现金。

【24:58】Feldman 补充，卖硬件并不消除行业机房延误：客户自己也要有地方放设备。他把公司定义成一门生意、两条商业路径：客户买设备装进自有机房，或租 Cerebras 自营云。他认为长期毛利率会接近，但现金流影响不同。这是管理层预期，没有给实际分部毛利表；不能忽略装机与验收对收款的影响。

【25:43】他说迄今主要看到云，现在部分客户有机房的硬件合同开始兑现，Oracle、AWS 设备装在各自机房，可能带来较大单季收入跳升。被问相对规模，他称初期 Oracle 机会比 AWS、Microsoft 机会大两倍以上，预计次年二季度开始。原话未精确定义是分别还是合计比较，因此不替他给出美元数或精确倍数模型。

【26:41】Feldman 预计明年不止一个季度硬件收入高于云，并说卖硬件对现金流有利。Gavin 引述市场预期明年消耗约 25 亿美元现金，认为若硬件贡献很大未必如此。Feldman 说，除非公司继续加速数据中心部署才会达到那种现金使用。它是有条件的讨论，不等于承诺明年不烧钱或给出新的全年现金指引。

【27:22】双方接着说，如果投入继续加速，云收入也会更大；应把现金消耗与部署规模、未来收入一起分析，不能机械把烧钱数字当经营好坏。随后 Gavin 以多年相识转问黄仁勋。这个转折保留了资本强度与增长选择的关系，也说明两人没有在本场完整给出可独立复算的现金流桥。

【28:18】Feldman 说，创业者梦想把公司长期建成最有价值企业，黄仁勋实现了这一点；他认为其过去十五至二十年的 CEO 表现堪称行业甚至跨行业顶尖，并明确不评论其他事情。此段是个人评价，不是关于公司人事的新增事实。Gavin 用 NBA 新秀与乔丹比喻提醒竞争者保持尊重，双方也谈到彼此竞争心。

【29:06】Feldman 说，公司要靠产品获胜，不在意其他噪声；如果做不到就应输。他认为测试过的客户认可速度，快推理带来远大于供给的需求。这里是管理层的自信与客户观察，未披露统一客户样本或服务级别数据，不能把其“最快”自称转换成覆盖所有模型的独立排名。

【29:51】Gavin 说公司可以与 Trainium、AMD、NVIDIA 合作，Feldman 认同当代科技企业必须学会与伙伴同时竞争。他以 Cisco、Salesforce 与 Microsoft 的交叠关系说明，这也是自己在学习的经验。分离推理给这种竞合提供技术空间，但不等于每个合作关系都已落实同样订单或合同条款。

教育、社区与未来企业：完整保留最后三问

【30:39】结尾第一道公共价值问题，Feldman 选择教育。他认为个别辅导的有效方式早为人知，只因贵，长期主要属于精英；拿亚历山大与亚里士多德作例子，是为了说明资源差别。他不是在台上提供现代教育试验，而是在提出为什么普遍可得的 AI 辅导具有社会意义。

【31:18】他举八岁孩子做长除法或解方程：ChatGPT、Claude 可以换八种、十种甚至更多解释，孩子只需说“我不懂，能换一种讲吗”。他认为这把过去昂贵私人导师的部分功能普及给更多人。这里并未比较测验成绩、错误率或可达性；“免费给所有人”是其概括，不能推出每种产品和功能均无限免费。

【32:07】被问 Cerebras 自己做什么，Feldman 先厘清公司是机房租户而非建设商，但仍与建设伙伴共同参与美国各地社区。他认为数据中心可以做良好邻居，批评早期一些开发者不透明而造成反弹。其责任观是租户不能因为不是开发商就完全置身地方关系之外；并不代表所有开发商都采取同一种做法。
